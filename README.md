# 🧬 Conway's Game of Life

<br>

## 📖 Description

This project is an implementation of **Conway’s Game of Life**, built using:

> 🌐 HTML <br>
> 🎨 CSS <br>
> ⚡ JavaScript 

<br>


The **Game of Life** is a cellular automaton created by mathematician **John Conway** in 1970.

The simulation is based on a **2D grid** of cells where each cell can either be:

> ⚫ Alive (black) <br>
> ⚪ Dead (white) <br>


At every generation, cells evolve automatically according to a set of rules based on their neighbors.

This project allows users to:

    - Create custom patterns
    - Start / Pause the simulation
    - Reset the board
    - Observe how cells evolve over time
    - Control the simulation speed

<br>

## 📜 Rules

Each cell has **8 neighbors** around it.

At every generation:

- 🔹 A living cell with fewer than 2 neighbors dies  
  → *underpopulation*

- 🔹 A living cell with 2 or 3 neighbors survives

- 🔹 A living cell with more than 3 neighbors dies  
  → *overpopulation*

- 🔹 A dead cell with exactly 3 neighbors becomes alive  
  → *reproduction*

<br>

All cells update simultaneously.
